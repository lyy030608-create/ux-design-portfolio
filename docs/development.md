# Phase 2 开发说明

当前实现 Home、Dose of Truth、Resume。Home 中 Visual Design、About、Contact 为页内区块；其余两个项目仅有真实素材预览，未伪造完整案例入口。

运行：Node 22+；在项目目录执行 `npm ci`，`npm run dev`。正式检查：`npm run build`，`npm run preview -- --port 4173`。在允许本地浏览器连接的执行权限下运行 `node scripts/verify.mjs`（依赖项目已安装 Taste Skill）。预览进程不会随云环境发布而保存，后续任务需重新启动。

路由使用浏览器 History API。当前 Vite 提供刷新回退；部署时必须配置 SPA fallback。尚未为 GitHub Pages 子路径配置，不可直接声称可部署到仓库子路径。

## 内容与素材来源

所有项目与视觉图片均从用户上传PDF中裁取，无第三方作品替代。Dose最终界面来自研究生作品集第17页；纸质原型和V1来自第15页；V2来自第16页。首页Karaoke来自第8页，Message Drift来自第24页；视觉作品来自本科PDF第6、8、10页。简历PDF原样保留。新Screen showcase/A1与旧作品集存在界面差异，后续应确认采用哪套最终界面；本版采用原作品集V5，未混合两套广告素材。

研究数据采用用户确认的团队13份问卷/13次测试，未沿用旧PDF第13页12访谈/30问卷数字。Message Drift贡献按用户确认以简历为准。

## 视觉决策与检查

Taste方向：type-only-statement（从三个方向中选择，未重抽）。把视觉传达转向UX的背景，转化为文字开场、真实界面作为证据的编辑式阅读顺序。字体、暖白底、粉紫橙渐变遵循用户Enblox参考，优先于Skill默认禁用渐变/紫色的规则。

真实交互：案例章节跳转、三个页面导航、移动菜单、真实素材放大与原始简历PDF。无额外虚构项目交互。

首轮截图审查发现：低保真与V1裁图带入原稿文字边缘；手机项目短句折成4行；辅助文字对比度偏低。均已调整裁图、构图与文字颜色。初步人工评价：信息结构8/10、视觉7/10、素材清晰度6/10（PDF嵌入图片限制）、可用性8/10；为自评，不是外部评审或正式Skill评分。

构建通过。验证覆盖1440/768/390三个宽度与3条路由，图片实际解码、横向溢出、H1、导航、弹窗、手机菜单、PDF响应及文件头。Taste严格规则仍有与用户视觉选择不一致及动效/字号等提示，不宣称0 FAIL。PDF内容已作为HTML完整表达，浏览器原生PDF内嵌能力受客户端支持影响。

尚未公开部署；当前环境聊天没有可分享的网页预览工具，不能把localhost当外部预览链接。截图仅用于静态审阅。待用户确认这一批方向后再扩展其余独立案例与视觉作品库。
